Projects

Selected projects

Pose · Segmentation · 3D mesh

Virtual Fitting Room

Extracts body measurements from a single video by reconstructing a 3D avatar. The pipeline estimates pose, segments the body, fits a parametric 3D mesh with Meta MHR, and shows the result in a web viewer.

  1. Video
  2. Pose estimation
  3. Body segmentation
  4. Measurements
  5. 3D mesh (Meta MHR)
  6. React + Three.js viewer

I used ONNX Runtime for low-latency inference and documented and fixed production failure modes along the way.

github.com/Catharin-05/virtual-try-on

Detection · Tracking · Agentic GenAI

Construction Video Intelligence

An agent that answers natural-language questions about long industrial video. A motion gate and a coarse-to-fine search keep detection cheap, so long videos can run on ordinary hardware.

  1. Video feed
  2. Motion gate
  3. YOLOv8
  4. ByteTrack
  5. LLaVA
  6. LLM agent

The agent uses tool calling and metadata caching to answer questions about what happened in the footage.
